# DAV-LAB

This repository contains the programs and datasets for the **Data Analytics and Visualization (DAV) Lab**.

## Experiments

### Experiment 1

Basic data analysis and manipulation using Python.

### Experiment 2

Data handling and processing using CSV, Excel, and other datasets.

### Experiment 3

Exploratory data analysis and statistical analysis of datasets.

### Experiment 4

Data preprocessing, cleaning, filtering, and transformation.

### Experiment 5

Data visualization and analysis using Python visualization libraries.

## Datasets

The programs use datasets such as:

* Iris Dataset
* Diabetes Dataset
* Pima Diabetes Dataset
* Marks Dataset
* CSV datasets
* Excel datasets

## Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
